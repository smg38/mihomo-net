Установка Mihomo

Определите вашу операционную систему и выберите способ установки. Скрипты разворачивают Mihomo. За подпиской обращайтесь.

Windows Linux Android iOS / iPhone

Windows

Способ A — скрипт установки

Требуется PowerShell 7.4+ и права администратора.

Скачать install.ps1 Скачать uninstall.ps1

После скачивания откройте PowerShell от имени администратора и выполните:

Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1 -ConfigUrl "URL_ПОДПИСКИ"

Удаление:

.\uninstall.ps1

Способ B — Kwik (GUI, проще)

Одна кнопка, встроенный TUN, kill switch, автозапуск. Рекомендуется, если не нужен CLI.
Скачать Kwik с GitHub

После запуска вставьте URL подписки в интерфейсе Kwik.

Способ C — FlClash (GUI, альтернатива)

Скачать FlClash с GitHub

Профили → Импорт → вставить URL подписки → Активировать.

Linux

Способ A — скрипт установки

Скачать install.sh Скачать uninstall.sh

Или одной командой (замените URL_ПОДПИСКИ и HOST):

curl -fsSL http://HOST/linux/install.sh | bash -s -- --config-url "URL_ПОДПИСКИ"

Удаление:

curl -fsSL http://HOST/linux/uninstall.sh | bash

Способ B — готовый GUI-клиент

Clash Verge Rev — AppImage / deb / rpm: скачать с GitHub.

Mihomo Party: скачать с GitHub.

В обоих: Профили → Импорт по URL → вставить адрес подписки.

Android

Magisk / KernelSU / APatch не используем. Только обычные приложения из F-Droid или GitHub.

Способ A — FlClash (рекомендуется)

Скачать FlClash с GitHub

Профили → Добавить → вставить URL: URL_ПОДПИСКИ → Импорт → активировать профиль → разрешить VPN.

Способ B — Clash Meta for Android (CMFA)

Скачать CMFA с GitHub

Или из F-Droid: com.github.metacubex.clash.meta.

Профили → Новый профиль → URL → вставить адрес → сохранить → нажать на профиль для активации.

iOS / iPhone / iPad

Apple не разрешает устанавливать сторонние VPN-профили напрямую без App Store. Нужно одно из приложений ниже. Все они платные, но есть бесплатные альтернативы.

Stash (рекомендуется)

Открыть в App Store

Платно. Профили → + → Подписка → вставить URL_ПОДПИСКИ → Импорт → Выбрать профиль → Подключить.

Shadowrocket

Открыть в App Store

Платно. Профили → + → Subscribe → вставить URL → Готово → выбрать профиль → подключить.

Бесплатные альтернативы

Streisand: App Store. V2Box: App Store.

Если приложение не открывается — обновите iOS до последней версии. Для iPhone без App Store (jailbreak) поддержка не гарантируется.
