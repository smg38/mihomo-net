# Точки восстановления

[← Назад к README](../README.md)

## Каталог .update-state/

| Файл | Назначение |
|---|---|
| `confirmed.json` | Подтверждённая работоспособная конфигурация |
| `transaction.json` | Незавершённая транзакция |
| `status.json` | Текущий статус задачи |
| `failed.json` | Неудачный кандидат (для остывания) |
| `deployment.pending` | Незавершённая публикация |
| `update.lock` | Блокировка обновления |
| `download-dns` | Предпочтение DNS |
| `providers/` | Кэш провайдеров |

Права: каталог `0700`, файлы `0600`. Содержат конфигурацию подписки —
**запрещено коммитить или публиковать**.

## Транзакция обновления

1. Проверка Google через `127.0.0.1:7890` (окно 5 секунд, HTTPS 204)
2. Подтверждение текущей конфигурации как работоспособной точки восстановления
3. Загрузка в приватный каталог-кандидат, локальные переопределения, подготовка провайдеров, `mihomo -t`
4. Остановка ядра, сохранение байтов конфигурации, CIDR и провайдеров в снимке
5. Перезапуск Mihomo, ожидание готовности до 15 секунд
6. Независимое 5-секундное окно приёмки Google, восстановление выбора стратегии
7. Только после успеха — запись применённого хэша

## Результаты

| Результат | Значение |
|---|---|
| `updated` | Успешное обновление |
| `unchanged` | Конфигурация не изменилась |
| `rejected` | Обновление отклонено, текущая конфигурация не изменена |
| `rolled_back` | Обновление не удалось, старая конфигурация восстановлена |
| `recovery_failed` | Обновление не удалось, восстановление также не удалось |

Успешный откат всё ещё означает сбой этого обновления. Если после
восстановления Google всё ещё недоступен, это явно сообщается.

## Восстановление после сбоя

Менеджер при запуске и следующем обновлении восстанавливает неподтверждённые
транзакции. При повреждении снимка или сбое записи файла восстановление
останавливается, запись транзакции сохраняется для проверки, точка
восстановления **не удаляется**.

## Что восстанавливается

| Файл | Восстанавливается |
|---|---|
| YAML подписки | ✅ |
| `cn_cidr.txt` | ✅ |
| Временная метка загрузки | ✅ |
| Провайдеры | ✅ |
| `.env` | ❌ |
| Бинарный файл ядра | ❌ |
| Код проекта | ❌ |

Ранее вручную выбранные стратегии по возможности сохраняются по имени.
Группы или узлы, удалённые в новой конфигурации, используют выбор
по умолчанию новой конфигурации.

## Временные метки

Промежуточное копирование, установка публикации и откат сохраняют исходное
время модификации, чтобы не принять старые ресурсы за только что обновлённые.

При отсутствии времени обновления в старой записи восстановление выполняется
с неизвестным временем, новое время загрузки не подделывается.
