## Незавершённая публикация

**Симптом:** обычная публикация многократно останавливается на этапе
автоматического восстановления.

**Причина:** старый пакет восстановления повреждён (например, unit-файлы).

**Решение:**

```bash
mise run publish -- --force
```

Сохраняет старый пакет по исходному пути, пропускает восстановление,
переустанавливает по текущему состоянию.

## Незавершённое обновление конфигурации

Обычное обновление отказывается выполняться до завершения восстановления
публикации.

```bash
mihomo-manager update --recover-only
```

## Проблемы с DoH

**Симптом:** загрузка не удаётся, DoH не помогает.

**Проверьте:**

- Версию curl (`curl --version`) — требуется 7.62.0+
- `DOWNLOAD_DOH_SERVERS` в `.env`
- Доступность сети (при полном отключении DoH тоже не поможет)

**Примечание:** при полном отключении сети DoH не может восстановить
соединение. Прозрачный прокси хоста всё ещё может влиять на HTTPS.

## Проблемы с подпиской

**Симптом:** `CONFIG_URL` недоступен.

**Проверьте:**

- URL в `.env`
- Доступность с сервера
- Наличие прокси/VPN
