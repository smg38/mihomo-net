# Командная строка и cron

[← Назад к README](../README.md)

## update.sh

```bash
./scripts/update.sh                    # автообновление, кандидат остывает 5 минут
./scripts/update.sh --retry            # немедленная повторная попытка
mihomo-manager update --recover-only   # восстановление незавершённой транзакции
```

## Коды выхода

| Код | Значение |
|---|---|
| `0` | Обновление успешно / без изменений |
| `1` | Подготовка или проверка отклонена |
| `2` | Обновление не удалось, выполнено восстановление (включая аномалию) |
| `3` | Блокировка обновления занята |

Ручное исправляющее обновление при недоступности Google **не блокируется**
сбоем базовой линии.

## Настройка cron

```bash
crontab -e
```

Пример — ежедневное обновление в 01:00:

```
0 1 * * * /root/mihomo/scripts/update.sh >> /root/mihomo/log.txt 2>&1
```

**Важно:** точка входа cron использует `REMOTE_DIR/scripts/update.sh`.
После изменения каталога обновите существующий путь cron.

## Поведение при сбое

Сообщение задачи сохраняет причину сбоя команды и диагностический вывод
до 32 KiB в конце. Превышение лимита явно отмечается усечением.

Исходный вывод скрипта записывается в journal менеджера. Сообщения страницы
удаляют ANSI-цвета. Конечное состояние после отката сохраняет причину сбоя
инициировавшего обновления.
