# Загрузка файлов и DNS

[← Назад к README](../README.md)

## Единая реализация

Вся загрузка идёт через `deploy/lib/http.sh`. Особенности:

- Единый общий лимит времени на все попытки
- Временный файл заменяет цель только после успешной загрузки
- Не читает `.curlrc`, не использует HTTP-прокси из окружения
- Удаляет управляющие символы терминала, но не изменяет адрес и заголовки

## Восстановление DNS

Порядок разрешения:

1. Системный DNS (если есть успешная запись)
2. AliDNS (`dns.alidns.com:223.5.5.5`)
3. Cloudflare DoH (`cloudflare-dns.com:1.1.1.1`)

Успешный способ сохраняется в `.update-state/download-dns`. Последующие
установки и загрузки переиспользуют его. При сбое — перебираются остальные.

**Важно:** кэшируется только способ разрешения, а не сопоставления домён-IP.
Каждый запрос разрешается заново.

## DoH-серверы

Формат `DOWNLOAD_DOH_SERVERS`:

```
host:bootstrap-IP host:bootstrap-IP ...
```

Поддерживаются IPv4 и IPv6. Путь службы — `/dns-query`.

- Пустое значение отключает внешний DoH
- Клиент может указать собственный DoH во внутренней сети
- DoH отправляет только разрешаемый домён, без пути подписки и токена
- Встроенный DoH curl разрешает домён после перенаправления

Требуется curl **7.62.0+** с поддержкой DoH.

## Прогресс загрузки

`DOWNLOAD_PROGRESS`:

| Значение | Поведение |
|---|---|
| `auto` | Прогресс при интерактивном терминале |
| `bar` | Принудительно |
| `off` | Отключено |

При известной длине — процент, при неизвестной — индикатор активности curl.
Мгновенно завершающиеся файлы всё равно имеют журнал завершения.

## Журнал загрузки

Полный URL текущего источника, начальные и конечные байты. При смене источника —
новый URL. Запись предпочтения DNS молчалива при нормальном переиспользовании,
при сбое добавляется способ разрешения и код ошибки.

Публичные адреса загрузки, подписки и provider **отображаются полностью**,
включая путь, параметры, учётные данные и фрагмент, **без маскировки**.

## Источники после сбоя

| Источник | Поведение |
|---|---|
| GitHub API | Пробует прокси, затем официальный источник |
| Релизы ядра | То же |
| Панель MetaCubeXD | То же |
| Подписка | Только исходный адрес (приватность) |
