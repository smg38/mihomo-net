## Структура проекта

```text
mihomo-net/
├── cmd/mihomo-manager/main.go   # Точка входа, обрабатывает код выхода
├── internal/manager/            # API, транзакции, время выполнения
│   ├── *_test.go                # Тесты в том же пакете
│   └── web/index.html           # Встроенная страница (go:embed)
├── scripts/publish.sh           # Обнаружение, кросс-компиляция, публикация
├── deploy/                      # Источник пакета времени выполнения
│   ├── install.sh               # Подготовка и установка
│   ├── release.sh               # Транзакция публикации
│   ├── scripts/update.sh        # Обновление конфигурации
│   ├── scripts/entrypoint.sh    # Запуск Mihomo + прозрачный прокси
│   ├── lib/                     # dotenv, контракт цели, HTTP
│   └── systemd/*.service.in     # Шаблоны unit-файлов
├── tests/deployment/            # Независимые тесты публикации
├── docs/                        # Документация
├── .env.template
├── go.mod
└── mise.toml
```

`cmd` зависит от `internal/manager`. Внутренняя реализация менеджера
**не раскрывается** как публичная библиотека.

Страница управления компилируется в бинарный файл через `go:embed` —
не требует загрузки отдельного HTML и не зависит от файлов в каталоге запуска.
Внешняя панель MetaCubeXD загружается в `ui/`.

## Компоненты

| Компонент | Роль |
|---|---|
| Ядро Mihomo | Прокси-движок |
| Systemd | Управление службами, автозапуск |
| NFTables | Перехват и перенаправление трафика TProxy |
| Go-веб-сервис | Бэкенд-API панели |
| Веб-фронтенд | Интерфейс пользователя |

## Каталоги

| Каталог | Роль |
|---|---|
| `REMOTE_DIR` | Продакшн-каталог |
| `deploy/` | Источник пакета времени выполнения |
| `.tmp/` | Локальная сборка |
| `.update-state/` | Приватные точки восстановления |

В продакшн-каталоге `.env`, `config.yaml`, `cn_cidr.txt`, `.update-state/`
и `ui/` — локальная конфигурация и состояние. Публикация не перезаписывает
существующий `.env` и не перемещает эти данные.

## Режимы прокси

### Прямое подключение
Прокси применяется только к трафику, соответствующему правилам. Подходит
для лёгких сценариев, низкое потребление ресурсов.

### Прозрачный прокси
Перехватывает весь сетевой трафик. Не требует настройки клиентских
приложений, поддерживает все протоколы, автоматически разделяет
внутренний и внешний трафик.

### Боковой роутер
Сервер как прокси-шлюз локальной сети. Устройства не требуют отдельной
настройки, поддерживаются смешанные сетевые среды.

## Поток публикации

```
publish.sh
    ├─ Обнаружение цели (только чтение)
    ├─ Кросс-компиляция
    ├─ Загрузка во временный каталог
    └─ release.sh
        ├─ install.sh --prepare
        ├─ mihomo-manager update --prepare-only
        ├─ backup_release
        ├─ install.sh --apply
        ├─ mihomo-manager update --prepared
        └─ Проверка готовности HTTP
```
